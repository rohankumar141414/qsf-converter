How should my file be formatted?

Excel / CSV (recommended for forms)

One row per question. Column names are flexible. These are all recognised:

ColumnAlso recognised asWhat goes in it
QuestionField Name, Label, Item, PromptThe question text (required)
TypeField Type, Question Type, FormatText, Long Text (Max 500 words), Dropdown, Checkbox, Radio, Yes/No, Date, Email, Phone, Number, Matrix, Likert, Slider 0-10, Rating 1-5, Stars, Rank, NPS, Constant sum 100, Form, Descriptive, File Upload (PDF), Signature
ChoicesOptions, Answers, ValuesSeparated by ; | / or new lines. Or use columns Choice 1, Choice 2, …
SectionCategory, Block, Group, PartEach section becomes a Qualtrics block with its own page and heading
RequiredMandatory, CompulsoryYes / No
Help textDescription, Guidance, Hint, NotesShown under the question. For dropdowns and choice questions, a list like Male / Female / Other is read as the choices.
IDField ID, Variable, CodeUsed as the Qualtrics export tag (e.g. F01)
ScaleColumnsMatrix column labels

Word, PDF and text files

  • Start each question with a number: 1. 1) Q1 or Question 1:. Word's automatic numbering works too.
  • Put each answer choice on its own line, starting with a) (b) - • ☐, or with no marker if the question ends in ? or :
  • Sections: a heading like Section A: About you, a Word heading, or a bold line.
  • Mark required questions with * or (required) at the end.
  • Set the type with a tag at the end: [dropdown] [multi] [email] [date] [number] [long text max 300 words] [matrix] [rank] [nps] [slider 0-10] [stars] [constant sum 100] [file] [signature]
  • Matrix: list the statements as choices and add a line Scale: Disagree / Neutral / Agree. In Word, a table with the scale across the top row and statements down the first column also works.
  • Questions with no choices are guessed from their wording (email, phone, date, number, long answer) and otherwise become short text boxes.

3 Review and edit

Check what was detected. You can change any question's type, text, help text, section or required setting, and reorder or delete questions. Each section becomes its own Qualtrics block.

4 Download for Qualtrics

Import into Qualtrics

  1. In Qualtrics, choose Create a new project → Survey → From a file (or, in an existing survey, Tools → Import/Export → Import survey).
  2. Upload the downloaded .qsf file.
  3. Check the survey in the editor. Date questions use Qualtrics' date check; choose the date format (e.g. DD/MM/YYYY) in the question's validation settings. File upload size and file-type limits are also set there.

Free and open source. Files are processed locally in your browser. Not affiliated with Qualtrics. Which question types a free account allows can change, so check in Qualtrics if an import fails.
