How should my file be formatted?

Word, PDF and text files

  • Start each question with a number: 1. 1) Q1 or Question 1:
  • Put each answer choice on its own line, starting with a letter or bullet: a) (b) c. - • ☐ — or no marker at all if the question ends with ? or :
  • Leave a blank line between questions.
  • Questions containing “select all that apply”, “check all”, or using ☐ boxes become multiple-answer. Everything else is single-answer.
  • Optional tags at the end of a question: [multi] [single] [dropdown] [text]
  • A choice like “Other (please specify)” gets a text box automatically.
1. What is your gender?
a) Male
b) Female
c) Prefer not to say

2. Which devices do you own? (Select all that apply)
- Phone
- Laptop
- Other (please specify)

Excel and CSV files

Use the first sheet with a header row. Required: a Question column. Optional: a Type column (single, multi, dropdown, text) and either a Choices column (separated by ; or |) or one column per choice (Choice 1, Choice 2, …).

QuestionTypeChoices
What is your gender?singleMale; Female; Prefer not to say
Which devices do you own?multiPhone; Laptop; Tablet

No header row? Column A is read as the question and the remaining columns as choices.

2 Review and edit

Check what was detected. You can fix question text, change the type, edit choices (one per line), reorder or delete questions.

3 Download for Qualtrics

Import into Qualtrics

  1. In Qualtrics, choose Create a new project → Survey → From a file (or open an existing survey and use Tools → Import/Export → Import survey).
  2. Upload the downloaded .qsf file.
  3. Review the survey in the editor and publish.
